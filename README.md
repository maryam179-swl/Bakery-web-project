# Bakery-web-project
A comprehensive Bakery Management System built with Django and SQLite, designed to manage bakery operations including staff, inventory, products, customers, orders, deliveries, reports, and financial analytics through a modern admin dashboard.

⚙️ Installation

cd bakery-management-system
Create Virtual Environment
python -m venv venv
Activate Environment

Windows:

venv\Scripts\activate

Linux/Mac:

source venv/bin/activate
Install Dependencies
pip install django
Run Migrations
python manage.py makemigrations
python manage.py migrate
Create Superuser
python manage.py createsuperuser
Run Server
python manage.py runserver
